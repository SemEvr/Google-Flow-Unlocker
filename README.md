# Google Flow Unlock

Расширение для Chromium-браузеров и Firefox, которое изменяет клиентскую проверку региона на странице Google Flow. В репозитории находятся исходники обеих версий и архивы для установки.

## Установка

### Chrome, Edge и другие Chromium-браузеры

1. Скачайте и распакуйте репозиторий.
2. Откройте `chrome://extensions/` (в Edge — `edge://extensions/`).
3. Включите режим разработчика и нажмите «Загрузить распакованное расширение».
4. Выберите каталог `chrome`.
5. Откройте Google Flow и проверьте переключатель в меню расширения.

Chrome может показывать уведомление об отладке: расширение использует разрешение `debugger` для обработки загружаемого кода страницы.

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите «Загрузить временное дополнение».
3. Выберите `firefox/manifest.json`.

Временное дополнение необходимо загружать повторно после перезапуска браузера. Создание файла `.xpi` само по себе не подписывает расширение.

## Состав репозитория

| Путь | Назначение |
| --- | --- |
| `chrome/` | Версия с обработкой запросов через Chrome DevTools Protocol |
| `firefox/` | Версия с фильтрацией ответа через WebRequest API |
| `dist/` | Архивы расширений |
| `build_packages.ps1` | Упаковка исходников в ZIP и XPI |

В каталогах браузеров находятся манифесты, фоновые скрипты, интерфейс настроек, иконки и локализации.

## Сборка

Из корня репозитория выполните в PowerShell:

```powershell
.\build_packages.ps1
```

Скрипт обновляет `dist/google-flow-unlocker-chrome.zip`, `dist/google-flow-unlocker-firefox.zip` и `dist/google-flow-unlocker-firefox.xpi`.

## Ограничения

Расширение работает с клиентским кодом Google Flow. Оно не предоставляет подписку или доступ к аккаунту. Изменения на стороне сервиса могут нарушить работу патчей. Если сам сайт недоступен по сети, установка расширения не устраняет причину сетевого сбоя.

После изменения исходников перезагрузите расширение на странице управления дополнениями, затем обновите вкладку Flow.
